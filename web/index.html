      中文题卡预览

      修正一句字幕

      用于本素材后续分段与成片字幕；选段内另行修改的英文优先。中文题卡单独编辑，已生成成片保持原样。

      批量下载播放列表

      粘贴你收藏的播放列表链接，工具按列表顺序逐个下载视频和英文字幕；已下载的自动跳过。

      需要先通过顶部「Cookie 设置」导入 cookies.txt，否则下载不了自己的收藏和「稍后观看」。

      成批下载耗时较长，单个视频失败不会中断整批。下载完成后到「语法素材库 → 选择文件夹」导入这个目录即可分析。

      AI 智能分段

      向 DeepSeek 发送英文字幕并生成中文，会产生 API 用量。生成后可检查再加入素材列表。
