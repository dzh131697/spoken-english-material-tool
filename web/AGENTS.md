# 共享网页

- 正式页面是 `index.html`，由 Windows 和 Android 共用；根目录 `android-layout-preview.html` 是独立示例预览，修改它不会改变 APK。
- 发布准备页在 `publish.js` / `publish.css`：每条成片独立编辑平台文案和多画幅封面，PNG 直接保存预览画布。后端入口为 `app.py` 的 `save_publication()` / `generate_publication()` / `cover_frame()`；Android 启动时需复制发布静态资源与 `library.html`。新增成片保存选段快照，旧成片不能套用当前素材列表。
- 发布编辑区用 `selectPublishTab()` 切换面板；桌面保留封面、标题、简介、标签、参考，手机为封面、文案、参考（标题/简介/标签在文案页分区）。只隐藏面板，保留输入；验证失败应定位对应平台和输入。顶部保存与发布包作用于整条成片。
- 手机成片页负责版本预览、保存和更多菜单中的删除；发布列表只显示封面、两行摘要与编辑/发布包入口，不重复放播放器和删除按钮。封面新增比例时同步 `publish.js`、`app.py` 的尺寸/文件名及 Android `MainActivity` 单文件保存、打包白名单，保留旧比例键和文件名。
- Android 分支入口为 `isAndroid`、`setupMobile()`；手机页面切换查 `showMobilePage()`，连续选句查 `renderMobileSelection()`，素材保存查 `getClip()` / `save()`，AI 审核查 `applySegments()`。先定位元素 ID、事件和对应函数，再读必要范围。
- 保留 Windows 行为；手机编辑页必须能看到视频并试听，保留现有视频元素和切点逻辑。状态栏、刘海、键盘安全区域由原生 `MainActivity.onCreate()` 的 WindowInsets 处理，相关问题先查原生，避免叠加固定 CSS 顶部空白。
- 页面通过 `api()` / `job()` 调用本机后端，通过 `window.AndroidHost` 调用原生能力；改协议才读取对应后端或原生方法。
- 页面改动优先在根目录运行 `node test_android_web.cjs`，使用模拟项目、媒体与 Android 桥接；它能检查手机和桌面页面行为，不能证明真实视频播放、手机安全区域或系统安装正常。Playwright 已配置时直接复用，不重复安装。
- 仅需排版调整时检查相关页面和窄屏即可；涉及保存、桥接或桌面共用行为时跑对应回归。需要 APK 时再按 `android/AGENTS.md` 构建，不为每次页面检查先打包 Windows 版。
- 「本期编排」的「AI 按主题挑选」走 `/api/library/pick`（`library_pick()`），只从已分析例句里返回 id 并按顺序整理，不改写句子；生成专题项目仍复用 `library_topic()` 的多视频裁剪拼接。主页面「AI 智能分段」是单视频路径，两者入口分开，不合并成一个对话框。
- 电脑端素材库 `library.html` 按「导入与分析 → 挑选例句 → 本期编排」分步组织。用户已指出把所有控件堆在一页难用；常用预览、试听与加入按钮应放在一起，切点和标签修正按需展开，编排单独展示。改布局须检查 1366×768 等较矮窗口，避免主要按钮或中文释义被挤出可用区域。
- 句型分类按字幕实际结构持续积累，不限五类，也不把示例列表当成固定白名单；`I need + 名词` 与 `I need to + 动词原形` 应区分。目录来自已保存标签，AI 参考现有名称；旧数据仅在用户主动点击「整理旧句型」时付费重标，不重建中文或切点。
- 素材库只收「可练例句」：AI 可跳过不适合的字幕行，每段必须是能独立使用的单句，英文 ≤16 词、中文 ≤28 字（词数由本地硬卡，超长段丢弃但批次仍标记完成）；句型只标主干或开头结构、最多 2 个。不要退回「覆盖每条字幕、不遗漏」的归档式分段。`[music]` 等方括号标注由 `library_clean()` 清除，不进题卡。
- 「分析字幕」只补未完成批次；「重跑所选」调用 `/api/library/reanalyze`（`library_analyze(reset=True)`），清空该素材例句与批次后按当前规则全量重跑，必须带二次确认，明确提示会丢弃手动修正、重新计费；已生成的专题/成片是独立文件，不受影响。
- 「整理旧句型」让 AI 按输入顺序返回句型数组、本地 zip 回 sentence id，不再要求复述数据库编号；逐素材异常隔离，失败写入 `errors` 返回供重试。
- 安卓编辑页应让被调整内容与控制同时可见：封面固定预览、参数区内部滚动；题卡在编辑页同屏预览；选段/成片视频保持可见。验证必须实际滚动控件，不能只看页面初始截图。删除成片必须确认范围，不能删除原视频、字幕、选段或系统另存的副本。
